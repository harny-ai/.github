# Harny

Per-user memory, connected accounts, permitted actions and the action record for your agents.

Harny gives the agent inside your app, for each user: a memory of that user that stays accurate as facts change, their connected accounts (mail, calendar, files, notes, chat), actions on those accounts inside permissions you set, and a record of every action. One API key, your own model.

## Start

- Connect an AI agent: `https://mcp.harny.ai` (MCP). With no key it can set up an app for you.
- Python: `pip install harny` · TypeScript: `npm install @harny/sdk`
- Setup guide: https://harny.ai/auth.md · Docs: https://harny.ai/docs/mcp/overview
